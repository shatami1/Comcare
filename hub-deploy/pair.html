Caregiver Setup Guide

Set up one shared Recovery Hub for everyone supporting the patient.

START HERE

Follow these steps in order.

The primary caregiver completes setup once. Then every approved family member or caregiver joins with the same six-digit patient code.

  1. Enter the patient informationComplete Patient Basics, the daily schedule, accessibility needs, and help instructions below.
  2. Add the primary caregiverEnter the person who should receive the first update or help request.
  3. Add approved family membersList everyone allowed to follow the daily plan, receive updates, and communicate with the patient.
  4. Save before pairingSelect Save Patient Setup so every connected person receives the same information.
  5. Create and share one codeSelect Go to Pairing Code. Share that same six-digit code or caregiver link with each approved person. Do not create a different code for each person.
  6. Test the care circleAsk one caregiver to send a message, have the patient tap I’m Okay, and confirm every connected caregiver sees the shared activity.
