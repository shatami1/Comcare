# Comfort Care Static Site Update

This folder is ready to upload to GitHub and deploy on Vercel as a static site.

## What changed

- Backed up the current live comcare.store separately in `../backup_current_site`.
- Removed daily rental options from the updated order catalog.
- Added weekly and monthly Medline-based rental products.
- Added `home-care-packages.html` for buy-out home care packages.
- Added catalog CSV/Markdown files for future editing.

## Deploy to GitHub and Vercel

1. Create or open your GitHub repository.
2. Upload all files from this `updated_site` folder to the repository root.
3. In Vercel, import that GitHub repository.
4. Use default static site settings. No build command is required.
5. Set the output/root directory to the repository root.

## Important

This upload package excludes clinical gas and breathing-support products. Hygiene-sensitive products such as commodes, slings, cushions, wound care, and incontinence should usually be sold or handled with a sanitation process rather than rented casually.
